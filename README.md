# Simple Calculator

A clean and modern calculator application built with HTML, CSS, and JavaScript.

## Features

✨ **Basic Operations**
- Addition (+)
- Subtraction (−)
- Multiplication (×)
- Division (÷)
- Decimal support

🎨 **User Interface**
- Clean, modern design
- Responsive layout (works on desktop and mobile)
- Smooth button animations
- Color-coded buttons for different operations
- Large, easy-to-read display

⌨️ **Keyboard Support**
- Number keys (0-9)
- Operator keys (+, -, *, /)
- Enter key to calculate
- Backspace to delete
- 'C' key to clear

🛠️ **Controls**
- **C** - Clear the display
- **DEL** - Delete the last character
- **=** - Calculate the result

## How to Use

1. Open `index.html` in your web browser
2. Click on number buttons to enter values
3. Click on operator buttons to perform operations
4. Click "=" to see the result
5. Use "C" to clear the display or "DEL" to remove the last digit
